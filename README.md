# Атлас стран · НГШ

## Попробовать на Mac

Откройте **index.html** в Chrome, Firefox или Safari. Оставьте рядом папку **assets** и файлы проекта. Нажмите **Первый вход**, введите псевдоним и придумайте PIN из 4–12 цифр. Для нового браузера понадобится отдельный локальный профиль. Контуры всех 195 государств и лиса входят в комплект. Кот школы и изображения флагов загружаются через интернет. При недоступности изображений игра показывает системные флаги-эмодзи, если их поддерживает устройство.

Для общего списка заданий, входа с разных устройств и школьной доски рекордов подключите Supabase. У пробного режима на одном устройстве и школьного сайта отдельные профили и результаты.

## 1. Создайте проект Supabase

1. Откройте [панель Supabase](https://supabase.com/dashboard), нажмите **Continue with GitHub** и войдите под своим аккаунтом.
2. Нажмите **New project**, выберите свою организацию, задайте имя **countries-trainer**, придумайте пароль базы, выберите регион и нажмите **Create new project**. Дождитесь готовности проекта. Пароль базы понадобится только владельцу.
3. Слева откройте **SQL Editor → New query**. Откройте файл **supabase/setup.sql** из комплекта текстовым редактором, скопируйте **всё содержимое**, вставьте в пустой запрос и нажмите **Run**. Ожидаемый результат — **Success**. Если переходите с версии с одним видом ответа, запустите новый скрипт целиком в том же проекте. Он обновляет функцию игры и добавляет поля даты и комментария, сохраняя существующие задания и результаты.
4. Откройте **Authentication → Sign In / Providers**. Разрешите регистрацию новых пользователей (**Allow new users to sign up**), включите провайдер **Email** и в блоке **User Signups** над списком провайдеров выключите **Confirm email** и нажмите **Save changes**. Минимальная длина пароля — 6. Оставьте разрешёнными пароли из цифр для существующих профилей. Игрок может выбрать PIN от 4 цифр: для PIN из 4–5 цифр приложение автоматически формирует более длинный пароль для Supabase. Игра создаёт технический идентификатор из имени ребёнка. Детская почта не требуется. Эта настройка относится к отдельному проекту игры.
5. В верхней части проекта откройте **Connect**. Скопируйте **Project URL** и **Publishable key** (начинается с `sb_publishable_`). Ключ также доступен в **Project Settings → API Keys**.
6. Откройте **config.js** текстовым редактором. Замените две пустые строки своими значениями и сохраните файл как обычный текст. Получится:

   ```js
   window.ATLAS_CONFIG = {
     url: 'https://ВАШ-ПРОЕКТ.supabase.co',
     key: 'sb_publishable_ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ'
   };
   ```

7. Откройте **index.html** повторно. На форме входа должна появиться фраза «Профиль и прогресс доступны с любого устройства». После создания игрока и первого входа список общих заданий должен загрузиться. Если в нём видна ошибка функции atlas_play, проверьте шаг 3 и что URL относится к тому же проекту. Для проекта с выключенным Data API включите его в **Integrations → Data API** и разрешите схему **public**.

## 2. Опубликуйте на GitHub

1. Войдите как **andreysvirschevsky-ai** и откройте [создание репозитория](https://github.com/new). В поле **Repository name** введите **countries-trainer**, выберите **Public**, нажмите **Create repository**. Если такой репозиторий уже занят другим проектом, выберите свободное имя и используйте его в адресе сайта.
2. В пустом репозитории нажмите **uploading an existing file**. Для уже созданного репозитория с файлами это **Add file → Upload files**.
3. Распакуйте архив. Перетащите **содержимое** папки проекта в область загрузки. Нужны index.html, style.css, config.js, catalog.js, store.js, map.js, game.js и папка assets целиком. Включите также README.md и папку supabase с SQL-скриптом для дальнейшего обслуживания. В корне репозитория должен оказаться сам **index.html**. Нажмите **Commit changes**.
4. Откройте **Settings → Pages → Build and deployment**. В поле **Source** выберите **Deploy from a branch**, ниже выберите **main** и **/(root)**. Нажмите **Save**.
5. Когда на той же странице появится **Visit site**, откройте сайт. При указанном имени репозитория адрес будет **https://andreysvirschevsky-ai.github.io/countries-trainer/**. Он начнёт работать после успешного развёртывания GitHub Pages.

## 3. Проверьте общий режим двумя игроками

1. На сайте создайте первого игрока. Вставьте «Италия, Франция; Южная Корея», нажмите **Добавить страны**. Должны распознаться три страны.
2. Выберите вопрос **Название страны**, ответ **Столица**, способ **Ввод с клавиатуры**. Выберите дату (например, 25.11.2026, название «Задание на 25.11.2026») и при желании добавьте комментарий «Европа — флаги» и нажмите **Сохранить задание**, затем **Скопировать ссылку**.
3. Пройдите раунд. Ввод разными регистрами засчитывается. Нажмите **Посмотреть результат**.
4. Откройте ссылку в другом браузере или на другом устройстве. Создайте второго игрока. Проверьте, что сразу выбраны три страны и верные правила. Это же задание должно быть доступно и в выпадающем списке **Общие задания**.
5. Пройдите раунд вторым игроком. В **Доска рекордов → Это задание** проверьте две отдельные строки. Вернитесь под именем первого игрока и повторите страны в другом направлении. После второго успешного полного раунда посмотрите число в колонке **Выучено стран (2 верных ответа)**.

## Правила

* Выберите один вид подсказки и от одного до трёх видов ответа. Например, к названию страны выберите флаг и точку на карте, затем нажмите «Проверить ответы». Страна засчитывается за раунд, когда верны все части. Для названий и столиц можно выбрать ввод с клавиатуры. Для флага нужно выбрать картинку, для карты — нажать на страну. Кнопка «Развернуть карту» открывает карту на всё окно. Карта масштабируется колёсиком и кнопками, перемещается перетаскиванием. Маленькие страны отмечены точками, при приближении видны контуры.
* Задания сохраняют страны и режим. Ссылка содержит настройки и продолжает работать независимо от названия задания в списке. Разные дети могут открывать задания друг друга.
* После ответа видны выбранный и верный варианты. Для флагов это изображения, для карты — отметки на одной карте. Разбор ошибок можно раскрыть и после раунда.
* Страны в раунде идут по одному разу. Рекорд задания — наибольшее число верных ответов, затем наименьшее время. Рейтинг сравнивает одинаковые наборы и правила. При сортировке по времени показывает время лучшего раунда каждого игрока. Время чтения разбора исключается. В сетевом режиме время фиксирует сервер, поэтому в него может входить задержка связи.
* Общий счётчик — число уникальных стран с правильными ответами в двух разных завершённых полных раундах. Направление и способ ответа могут различаться. Повторы ошибок и прерванные игры не увеличивают счётчик.

## Источники

Политические контуры основаны на [Natural Earth](https://www.naturalearthdata.com/), public domain, масштабы 1:110 млн и 1:50 млн, проекция Робинсона. На карте также изображены территории вне учебного списка. Учебный набор — 193 государства — члена ООН и два государства-наблюдателя. Для государств с несколькими столичными функциями справочник принимает распространённые ответы, например Сукре и Ла-Пас для Боливии. Ярен используется как место расположения правительства Науру. Для выбора частей света у ряда стран предусмотрено несколько регионов.
